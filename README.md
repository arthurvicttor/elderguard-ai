# Elder Guard-AI

Sistema de visão computacional desenvolvido para auxiliar no monitoramento de idosos que vivem sozinhos, identificando possíveis situações de emergência.

## Sobre o projeto

O Elder Guard-AI tem como objetivo detectar situações potencialmente perigosas, como quedas, desmaios e posturas suspeitas, por meio da análise de movimentos corporais utilizando visão computacional e inteligência artificial.

Ao identificar uma possível emergência, o sistema deverá enviar uma notificação para um contato de emergência previamente cadastrado.

## Funcionalidades

- Detecção de quedas.
- Identificação de possíveis desmaios.
- Reconhecimento de posturas suspeitas, como movimentos de mão ao peito.
- Envio de notificações para contatos de emergência.
- Monitoramento assistido por inteligência artificial.

## Funcionamento

1. Captura de imagens por meio de uma câmera.
2. Análise de movimentos e posturas corporais.
3. Identificação de possíveis situações de emergência.
4. Envio de um alerta para o contato de emergência cadastrado.
